# Questionnaire Engine

A headless questionnaire engine with extensible question types, validation, formulas, and actions.

## Description

This is a TypeScript-based questionnaire engine that provides a flexible and extensible foundation for building dynamic forms and surveys. It supports multiple question types, validation rules, formula calculations, and conditional actions.

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Project Structure

```
src/
├── index.ts                    # Main exports
├── types/                      # Type definitions
├── engine/                     # Main engine
├── questions/                  # Question implementations
├── validation/                 # Validation system
├── formulas/                   # Formula engine
├── actions/                    # Action system
├── state/                      # State management
└── utils/                      # Utility functions
```
